
# Environment Variables Commands


# Debian/Ubuntu

-> Environment Variable operations
  =================================
  ```bash
  printenv                         # Displays all environment variables
  env                              # Displays the current environment variables.
  echo $HOME                       # Displays the user's home directory
  echo $USER                       # Displays the current username.
  echo $PWD                        # Displays the current working directory
  echo $SHELL                      # Displays the current shell
  export NAME=Sum                 # Creates or updates an environment variable
  echo $NAME                       # Displays the value of the NAME environment variable
  unset NAME                       # Removes the NAME environment variable
  set                              # Displays all shell and environment variables
